# Cross-origin lightbox close test

This is a minimal demo for closing a lightbox on origin A from an iframe on
origin B, without maintaining a domain whitelist.

It uses:

- `window.parent.postMessage(...)` from the iframe.
- `event.source === iframe.contentWindow` in the parent.
- A per-open random `closeToken`.
- `parentOrigin` passed from A to B so B can avoid `targetOrigin: "*"`.

## Run

Open two terminals from this folder:

```sh
cd /Users/imagine/package/FigmaToCode/sandbox/postmessage-lightbox/a
python3 -m http.server 5173
```

```sh
cd /Users/imagine/package/FigmaToCode/sandbox/postmessage-lightbox/b
python3 -m http.server 5174
```

Then open:

```txt
http://localhost:5173
```

Click the red X inside the iframe. The parent page should close the lightbox.

## Why this is cross-origin

Even though both pages are on `localhost`, different ports are different
origins:

- A: `http://localhost:5173`
- B: `http://localhost:5174`

## Security note

The parent does not use a fixed domain whitelist in this demo. Instead it
checks both:

- The message came from the expected iframe window.
- The message includes the random token generated by the parent.

For production, keep the token unguessable and one-time per lightbox open.
