Fonts shown in the plugin's "預覽下載版" and "並排比對".

Figma's plugin window cannot use fonts installed only for the current Windows user, so the
preview fell back to a serif font. These are copies of the same files the designers' Chrome
uses (from %LOCALAPPDATA%\Microsoft\Windows\Fonts), so the preview matches Chrome.
They are only used inside the preview; exported zips are unchanged.

Licenses: Roboto (Apache 2.0), Prompt (SIL OFL 1.1), Noto Sans Bengali (SIL OFL 1.1),
Pyidaungsu (free font published by Myanmar's Ministry of Transport and Communications).
Not included: Noto Sans CJK (about 16 MB per weight) and Microsoft JhengHei (Microsoft's,
not redistributable); the preview lists them when a page uses them.
